# Configuração Inicial do Ambiente

Antes de começarmos a realizar os testes, é necessário estarmos preparando o ambiente que utilizaremos. Para isso será instalado:

1. OracleVM: [https://www.virtualbox.org/wiki/Downloads]
2. Kali Linux premade VM: [https://www.kali.org/get-kali/#kali-virtual-machines]
3. Metasploitable2 VM: [https://sourceforge.net/projects/metasploitable2/]

Uma vez com os arquivos baixados, basta configurar as VMs da forma instruída no curso e iniciando as máquinas.

- Kali: Importa-se diretamente do arquivo baixado, com as configurações prontas. Caso desejar, trocar o nome da VM.
- Metasploitable2: "Novo" -> OS = Linux | OS Distribution = Ubuntu -> "Especificar espaço de armazenamento virtual" = ✓ "Utilizar um disco rígido virtual existente" -> Selecionar o arquivo dentro do diretório descompactado do Metasploitable2 -> "Finalizar"

Os usuários e senhas, respectivamente, padrão para acessar cada uma são:
- Kali: kali & kali
- Metasploitable2: msfadmin & msfadmin
